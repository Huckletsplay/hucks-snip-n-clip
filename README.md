# Huck’s Snip ’n’ Clip

Huck’s Snip ’n’ Clip is a lightweight macOS menu-bar utility for taking screenshots and recording short video clips, then routing each capture to the output you choose.

**Powered by Project Playground**

*Here for all your snippin’ and clippin’ needs.*

## Download for macOS

Download the latest free beta from [GitHub Releases](https://github.com/Huckletsplay/hucks-snip-n-clip/releases/latest).

The current build supports macOS 14 or newer and includes both Apple silicon and Intel Mac support.

## Install the unsigned beta

This early beta is not notarized through Apple’s paid Developer Program, so macOS will initially block it.

1. Download the DMG from the Releases page.
2. Open the DMG and drag **Huck's Snip 'n' Clip** into **Applications**.
3. Try to open the app once.
4. Open **System Settings > Privacy & Security**.
5. Scroll to **Security**, select **Open Anyway**, and open the app again.
6. Under **Privacy & Security > Screen & System Audio Recording**, enable **Huck's Snip 'n' Clip**.

macOS requests microphone permission only when you select a microphone recording mode.

## Features

- Region, window, and full-display screenshots.
- Region, window, and screen video clips with a 3–2–1 countdown.
- Fixed pause/resume and stop controls while recording.
- No Audio, System/App Audio, Microphone, and separate System/App + Microphone track modes.
- Configurable frame rate, resolution, quality, and independent audio gains.
- Named output locations that can be selected before a snip or clip.
- Rebindable keyboard shortcuts, including two-step shortcut chords.
- A live menu-bar H meter showing audio activity and CPU usage while recording.
- Local recovery and diagnostic files if a destination or recording operation fails.

## Privacy

Captures, recordings, settings, and diagnostics stay on your Mac. Huck’s Snip ’n’ Clip does not upload your captures to a cloud service. Files are written only to destinations you select or to the app’s local recovery folder when necessary.
