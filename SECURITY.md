# Security Policy

## Supported versions

Security fixes are applied to the latest public beta available through GitHub Releases.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a
public issue containing exploit details, private captures, credentials, or personal file paths.

Include the affected operating system, app version, reproduction steps, and expected impact. You
should receive an acknowledgment within seven days.

## Privacy boundary

Huck's Snip 'n' Clip is designed to keep captures local. It contacts GitHub only when the user
explicitly checks for an update. Reports that identify an unexpected network request, capture-path
escape, unsafe overwrite, or unintended screen/audio inclusion are especially important.
